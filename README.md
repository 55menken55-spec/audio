# Тихая глава — прототип студии записи

Лёгкий браузерный прототип для записи и базового монтажа собственного голоса на Windows. Записи не отправляются на сервер.

## Запуск на Windows

Нужны современный Chrome или Edge и Python 3. Откройте командную строку в папке проекта и запустите:

```text
py -m http.server 8000 --bind 127.0.0.1
```

Откройте http://localhost:8000 и разрешите доступ к USB-микрофону. Список микрофонов может отображать названия только после выдачи разрешения. Сервер должен оставаться запущенным во время работы. Папку с приложением можно скопировать на компьютер; запись и монтаж после запуска не требуют интернета. Открытие файла напрямую (`file://`) и приватный режим не рекомендуются.

## Что работает

- Запись с выбранного микрофона, пауза, метки, индикатор уровня, таймер и отображение сигнала во время записи (последние примерно 60 секунд).
- Выделение участка на дорожке мышью, прослушивание выделенного участка, отображение текущего времени и положения при прослушивании, удаление и приглушение, отмена последнего изменения.
- Сохранение отдельных проектов в хранилище браузера и экспорт PCM WAV (16 бит).
- Приближение дорожки (кнопки + и −) с горизонтальной прокруткой для точного выделения.
- Регулируемая сила приглушения (10–100%) и плавность перехода; кнопка «Убрать щелчок» заменяет короткий участок (до 0,1 с) плавной интерполяцией.
- Локальное шумоподавление по выделенному образцу: выберите 1–10 секунд фонового шума без речи, настройте силу и нажмите «Убрать шум». Обрабатывается вся дорожка. Прослушайте результат; при необходимости нажмите «Отменить». Сохраните WAV до обработки для резервной копии. Это простой фильтр для относительно постоянного шума, а не нейросеть: он может искажать голос и не предназначен для удаления дыхания или отдельных щелчков.

**Важно:** проекты находятся в хранилище конкретного браузера на конкретном компьютере. Очистка данных браузера может удалить их; сохраняйте резервные копии WAV. WAV содержит готовую дорожку, но не метки и не историю монтажа. Браузер может ограничивать размер хранилища; длинные записи потребляют много памяти (на ПК с 4 ГБ лучше записывать короткими частями). Приложение загружает всю запись в память и не является готовым профессиональным редактором; проверяйте экспорт до удаления исходных данных.

Это первый прототип, не финальная версия. Пока нет MP3, многократной отмены, склейки записей, автосохранения и переносимого файла проекта. WAV создаётся из текущей дорожки; удаление необратимо после сохранения проекта поверх прежней версии. Приглушение уменьшает выделенный участок на 80% с короткими переходами. Для работы с микрофоном нужен `localhost` или HTTPS. Системные разрешения и поддержка записи зависят от браузера и устройства.
